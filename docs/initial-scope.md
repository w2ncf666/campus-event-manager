# 第一版范围（讨论草案，尚未需求确认）

## 项目使用者

- 活动组织者：创建活动、管理报名、登记签到、查看统计。
- 活动参与者：浏览活动、报名、取消报名、查看候补状态（均待调研确认）。

## 模块设想

| 模块 | 初步设想 | 关键待确认问题 |
| --- | --- | --- |
| 活动管理 | 创建/编辑活动，配置名额和截止时间 | 管理权限、活动状态、是否允许修改报名中的活动 |
| 报名候补 | 报名、取消、满额候补、递补 | 候补排序、自动或人工递补、截止后规则 |
| 签到统计 | 组织者登记签到，查看和导出汇总 | 签到角色/方式、需要导出的字段及格式 |

不在第一版范围：支付、短信通知、学校统一登录。活动容量不是固定 20 人，应由组织者配置。

**先做用户访谈并核对老师要求，再确定正式需求和验收标准。**
