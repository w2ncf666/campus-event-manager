## 项目简介

本项目拟面向校园班级、社团等活动组织者及报名参与者，探索活动管理、报名与候补、签到与统计的简化流程。

**当前仅为选题草案，不等于已确认需求。** 候补顺序、递补方式、报名截止后的规则、导出字段等必须根据访谈结果确认。活动容量由组织者设置，不能把“20 人”写死。

第一版暂不考虑在线支付、短信通知、学校统一身份认证。
