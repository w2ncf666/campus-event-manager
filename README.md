# 社团活动报名与候补系统

三人课程小组项目，目前处于项目准备与需求调研阶段。

负责人发布活动并设置报名时间和名额。学生可以报名、查看结果和取消报名，满员后进入候补。活动当天由负责人登记签到，并查看报名和到场情况。

| 首版讨论范围 | 功能 |
| --- | --- |
| 活动管理 | 创建、发布和修改活动，设置报名时间和名额，关闭报名 |
| 报名与候补 | 报名、查看结果、取消报名、满额候补和递补 |
| 签到与统计 | 登记签到、查看到场名单、统计报名与出席、导出名单 |

20 人是演示示例，活动容量由组织者设置。候补顺序、递补方式、截止后的操作和导出内容待访谈确认。首版暂不纳入支付、短信通知和学校统一登录。

## 开始协作

1. 接受仓库邀请，然后按[小组项目上手指南](docs/setup-guide.md)克隆仓库并检查本机环境。
2. 按 [BMAD 安装说明](docs/bmad-guide.md)安装 BMAD 6.12.4，记录实际结果到[三人环境登记表](docs/team-environment.md)。
3. 访谈结果和课程要求明确后，先整理 Product Brief，再编写 PRD、设计架构和拆分故事。
