# 社团活动报名与候补系统

三人课程小组项目，目前处于首版需求的组内评审阶段。

负责人发布活动并设置报名时间和名额。学生可以报名、查看结果和取消报名，满员后进入候补。活动当天由签到岗登记签到和现场补录，财务按权限导出名单。

| 首版讨论范围 | 功能 |
| --- | --- |
| 活动管理 | 创建、发布和修改活动，设置报名时间和名额，关闭报名 |
| 报名与候补 | 报名、查看结果、取消报名、满额候补和递补 |
| 签到与统计 | 登记签到、查看到场名单、统计报名与出席、导出名单 |

活动容量由组织者设置。访谈评审稿采用 16 人场次作为验收示例，候补和现场规则待组会确认。首版暂不纳入支付、短信通知和学校统一登录。

## 首版评审材料

- [产品简述](_bmad-output/planning-artifacts/product-brief.md)
- [PRD 草稿](_bmad-output/planning-artifacts/PRD.md)
- [组会决议与分工表](_bmad-output/planning-artifacts/组会决议与分工.md)

组会先走查 PRD 的四个验收场景，再将结论和分工记入决议表。确认后把规则回填到产品简述和 PRD。

## 开始协作

1. 接受仓库邀请，然后按[小组项目上手指南](docs/setup-guide.md)克隆仓库并检查本机环境。
2. 按 [BMAD 安装说明](docs/bmad-guide.md)安装 BMAD 6.12.4，记录实际结果到[三人环境登记表](docs/team-environment.md)。
3. 组会确认规则并定稿产品简述和 PRD 后，再开始架构设计与故事拆分。
